---


## 📦 Sobre o Projeto

> Biblioteca online interativa. 

> Um gerenciador de livros em tempo real com autenticação e integração com API externa, "Feita para com o objetivo de ser um loja online de venda de livros". (Projeto integrador)

---

## 🚀 Tecnologias

Tecnologias e ferramentas utilizadas no projeto:

- [Dart](https://dart.dev/)
- [Flutter](https://flutter.dev)
- [PostgreSQL](https://www.postgresql.org/)

---

## 📋 Funcionalidades

- [ ] Cadastro e login de usuários
- [ ] Sistema de gerenciamento de livros
    - [x] Listar livros cadastrados
    - [x] Excluir livros
    - [ ] Editar cadastro de livros
    - [x] Ver detalhes do livro
    - [ ] Sistema admin para cadastro de usuários
    - [ ] Sistema de busca e pesquisa de livros
